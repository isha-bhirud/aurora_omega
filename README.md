AURORA: 
Airport Operations and Runway Management System

AURORA is a Python-based airport runway operations management system that uses a MySQL database to manage aircraft, airports, runways, and scheduled flight operations. It provides a graphical interface for viewing airport activity and manually assigning runways to landing and takeoff operations.

Features:
- Dashboard displaying aircraft, airports, runways, and scheduled operations.
- Manual runway assignment for scheduled arrivals and departures.
- Assignment validation based on airport alignment, direction suitability, aircraft compatibility, runway status, and active restrictions.
- Artos Radar for visualizing aircraft, runways, taxiways, and airport layouts.
- Fleet and Airports section for viewing aircraft, airlines, airports, and runway information.
- SQL Reports for database queries and operational reports.

Technologies Used:
- Python
- Pygame
- MySQL
- MySQL Connector
